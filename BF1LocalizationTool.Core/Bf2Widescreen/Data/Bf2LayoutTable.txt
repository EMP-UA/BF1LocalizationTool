#     ColorR/G/B). Значення поля може бути рядком у лапках (напр.
#     halign="hcenter") лише у звичайному рядку до побудови екрана — інші
#     механізми запису (@post, @hook, @globals, @screen, @initlist) приймають
#     тільки числа. Сегмент шляху виду "#N" (N — ціле число) — числовий ключ
#     таблиці Lua (t[N]), а не рядковий (t["N"]); застосовується для елементів
#     за числовим індексом (наприклад, груп радіокнопок). Якщо перший сегмент
#     шляху починається з `@post:`, `@initlist:` чи `@hook:` — це один із

#     ColorR/G/B). A field's value may be a quoted string (e.g.
#     halign="hcenter") only in an ordinary pre-build row — the other write
#     mechanisms (@post, @hook, @globals, @screen, @initlist) accept numbers
#     only. A path segment of the form "#N" (N an integer) is a numeric Lua
#     table key (t[N]), not a string one (t["N"]); used for elements stored
#     under a numeric index (e.g. radio-button groups). If the path's first

#     docs/BF2_MISSIONSELECT_LAYOUT.md for details); a path starting with
#     `@globals` writes to a Lua global variable rather than a widget field.
